# HBM Nuclear Shells

A small Forge 1.20.1 compat mod: the nuclear cannon shells from **CBC Enhanced Shells** and **CBC: Warium Projectiles** go off as the matching bombs from **HBM's Nuclear Tech (NTM Continuum)**.

| Shell | HBM bomb |
|---|---|
| Nuke Shell | Little Boy |
| Nuke Shell Mk2 | Fat Man |
| H-Bomb Shell | Ivy Mike (hydrogen bomb) |
| Mini H-Bomb Shell | high-yield mini nuke |
| Fission Bomb Shell (Warium) | Fat Man |
| Fusion Bomb Shell (Warium) | Ivy Mike |

Each can be changed in `config/hbmnukeshells-common.toml` (e.g. make the H-Bomb Shell a Tsar Bomba, or set one back to `NATIVE`). Blast sizes, fallout and clouds come from HBM's own config.

Needs HBM's Nuclear Tech; the shell mods are optional (it handles whichever you have).
